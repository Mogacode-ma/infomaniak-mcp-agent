# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)** verbatim. The full text is published by the Contributor Covenant maintainers and updated independently of this repository.

## Summary

Be respectful. Assume good faith. Disagree on the merits, not on the person. Empathy and kindness are non-negotiable in interactions on this project.

## Scope

This Code of Conduct applies to all project spaces — issue tracker, pull requests, discussions, and any official communication channel — and to public spaces when an individual is representing the project.

## Enforcement

Reports of unacceptable behavior may be sent privately to the project maintainers via the contact mechanism listed in [`SECURITY.md`](./SECURITY.md). All complaints will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter of any incident.
